Informativa privacy

Questo è un sito personale di Marco Scigliuolo, Bolzano. Non usa cookie, strumenti di statistica, pubblicità né contenuti incorporati da terzi. I caratteri tipografici sono ospitati sul sito stesso.

Il sito è ospitato su GitHub Pages (GitHub, Inc.). Per motivi di sicurezza GitHub può registrare l'indirizzo IP dei visitatori. Per i dettagli vale l'informativa di GitHub: GitHub General Privacy Statement.
