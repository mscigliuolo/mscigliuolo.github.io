Property Set per l'export IFC da Revit

Come far arrivare nell'IFC i parametri che il committente chiede, per esempio quelli della struttura dati della Provincia di Bolzano, con un file di testo e una configurazione di export.

guida genericaesempio con 3 parametrifile .txt scaricabileRevit 2026Edizione novembre 2026
1

A che cosa serve

Un Property Set definito dall'utente è un file di testo che dice all'esportatore IFC di Revit quali parametri del modello esportare, con quale nome, con quale tipo di dato e su quali classi IFC. È la via standard per portare nell'IFC i parametri condivisi richiesti dal committente, senza dipendere dai set di proprietà generici di Revit.

Un esempio concreto

Un committente pubblico chiede che ogni muro e ogni solaio dell'IFC riporti l'unità tecnologica secondo la sua classificazione. In Revit il dato c'è, in un parametro condiviso. Senza un Property Set non arriva nell'IFC, oppure arriva con un nome che nessuno riconosce.

Il file dei Property Set

Il file è fatto di blocchi: una riga di intestazione PropertySet: seguita dalle righe delle proprietà. Tutti i campi sono separati da un TAB, mai da spazi.

La riga di intestazione

PropertySet:⇥NomePset⇥I⇥IfcWall, IfcWallType
CampoContenutoNote
1PropertySet:Scritto attaccato, con i due punti. Property Set: con lo spazio non viene riconosciuto
2Nome del setNon usare i nomi dei set standard (per esempio Pset_WallCommon) e il prefisso Pset_
3IDa Revit 2024.1 Autodesk indica di usare sempre I, anche per i parametri di tipo
4Classi IFCSeparate da virgola. Per i parametri di tipo aggiungi anche la classe Type corrispondente (IfcWallType)

Le righe delle proprietà

⇥NomeInIFC⇥TipoDato⇥NomeParametroRevit
ColonnaContenutoNote
1Nome della proprietà nell'IFCÈ il nome che vedrà chi apre il file
2Tipo di datoText, Boolean, Integer, Real, Length, Area, Volume, Power… L'elenco completo è nel file di esempio di Autodesk
3Nome del parametro RevitDeve coincidere carattere per carattere, spazi e accenti compresi. I parametri di sistema si richiamano con BuiltInParameter.NOME
  • Le righe che iniziano con # sono commenti; spazi e TAB a inizio riga vengono ignorati.
  • Salva sempre in UTF-8: con accenti e dieresi un file in ANSI altera i nomi.
  • Usa un editor che mostri i caratteri invisibili (Notepad++, VS Code): vedi subito TAB, spazi e fine riga.
4

Un esempio con tre parametri

Un set con tre proprietà, applicato a muri e solai: un parametro della struttura dati provinciale, il contrassegno di Revit e un parametro Sì/No. Il nome del set e i nomi delle proprietà IFC sono di esempio: sostituiscili con quelli richiesti dal capitolato informativo.

Versione leggibile: ⇥ indica un TAB

# Esempio · UTF-8 · campi separati da TAB
PropertySet:⇥PBZ_Esempio⇥I⇥IfcWall, IfcWallType, IfcSlab, IfcSlabType
⇥UnitaTecnologica⇥Text⇥2-Technologische Einheiten_Unitá tecnologiche
⇥Contrassegno⇥Text⇥BuiltInParameter.ALL_MODEL_MARK
⇥Portante⇥Boolean⇥PBZ_Portante
Scarica il file con i TAB veri
  • La prima proprietà ha un nome di parametro bilingue, con spazi e un accento: va bene, perché il separatore è solo il TAB. Basta però uno spazio in coda, invisibile, per rompere la corrispondenza.
  • BuiltInParameter.ALL_MODEL_MARK richiama il Contrassegno con il suo nome interno, indipendente dalla lingua di Revit.
  • Boolean corrisponde ai parametri Sì/No.
  • IfcWallType e IfcSlabType servono solo se tra i parametri ce ne sono di tipo.
5

Impostare Revit, passo per passo

I nomi delle opzioni sono quelli dell'interfaccia inglese dell'esportatore IFC; in italiano possono cambiare leggermente.

  1. Controlla i parametri. Nel file dei parametri condivisi verifica il nome esatto di ogni parametro; nel progetto controlla che sia caricato nelle categorie giuste e compilato sugli elementi. I parametri vuoti non vengono esportati.
  2. Prepara il file Pset. Parti dal file di esempio, scrivi il tuo blocco con i TAB, salva in UTF-8 in una cartella stabile, per esempio quella degli standard di studio.
  3. Apri la configurazione di export. File → Esporta → IFC → Modify Setup. Duplica una configurazione esistente invece di modificare quella predefinita.
  4. Scheda Property Sets. Spunta Export user defined property sets e indica il percorso del file .txt. Valuta se lasciare attivi anche Export Revit property sets e Export IFC common property sets: aggiungono molte proprietà non richieste.
  5. Parametri di tipo. Se vuoi che i valori dei parametri di tipo finiscano nel set dell'istanza, attiva l'opzione che consente l'uso delle proprietà di tipo nei set di istanza, se la tua versione dell'esportatore la prevede.
  6. Mappatura delle classi. La corrispondenza categoria Revit → classe IFC si imposta in Revit: tabella di mappatura delle categorie, o parametro Export to IFC As sul singolo elemento. Le classi scritte nel file Pset devono essere quelle che gli elementi avranno davvero nell'IFC.
  7. Salva la configurazione con un nome parlante, per esempio IFC4_RV_Committente, ed esporta.
6

Verificare l'IFC

Apri il file esportato in un visualizzatore IFC, seleziona un elemento per ogni classe del set e controlla che il Property Set ci sia, con i nomi e i valori attesi. Un tipo di dato scritto male non blocca l'esportazione, ma la proprietà esce come testo: l'errore si nota solo quando qualcuno prova a filtrare per valore.

Tipi fisici per gli impianti

Per potenze, portate, correnti e trasmittanze usa i tipi fisici (Power, VolumetricFlowRate, ElectricCurrent, ThermalTransmittance) invece di Real: l'IFC porta anche l'unità di misura, e chi riceve il file non deve indovinarla.

Errori tipici e checklist

Errore nel fileEffetto
Spazi al posto dei TABLa riga viene letta come un campo unico: proprietà o intero set ignorati
Property Set: invece di PropertySet:Intestazione non riconosciuta, il blocco sparisce
Spazio finale dopo il nome del parametroNessuna corrispondenza con Revit, proprietà assente
Classe IFC diversa da quella esportataIl set non viene agganciato a quegli elementi
Parametro vuoto sull'elementoLa proprietà non compare
File salvato in ANSI con accentiNomi alterati, nessuna corrispondenza
Nome uguale a un set standardIl set viene rinominato dall'esportatore

Checklist prima dell'export

  • File salvato in UTF-8, campi separati da TAB
  • Intestazione PropertySet: con quattro campi; I nel terzo
  • Nome del set senza prefisso Pset_
  • Classi IFC coerenti con la mappatura; classi Type aggiunte se ci sono parametri di tipo
  • Nomi dei parametri identici al file dei parametri condivisi, senza spazi in coda
  • Parametri compilati sugli elementi da esportare
  • Configurazione di export salvata e collegata al file giusto
  • Controllo a campione nell'IFC: un elemento per ogni classe
